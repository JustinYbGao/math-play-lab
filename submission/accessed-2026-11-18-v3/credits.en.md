# Credits and provenance

## Earlier foundation

The UGREEN Math Play Lab work contributed the initial concept, a NAS/skill-oriented workflow, and a three-problem prebuilt Math Quest sample. That sample remains labeled as prebuilt and is not presented as an answer newly generated for an arbitrary question.

## Work in this iteration

The current work adds a general text-problem composer, online model generation, clarification and cancellation, structured activity contracts, an isolated player, browser validation and bounded repair, usage controls, a 141-topic evaluation corpus, inspection tools, exact arithmetic, shared assessment state, independent field probes, bounded numeric relationship grading, and an English presentation layer.

## Tools and AI assistance

- JavaScript, HTML, CSS, and Node.js implement the application.
- Chromium and Playwright run browser checks and replay interactions.
- OpenRouter provides model API access. The reviewed cohort used Claude Sonnet 5.5; earlier development experiments also used DeepSeek V3.2 and Sonnet 4.6.
- Codex coordinated tasks and performed separate implementation and behavior audits. Luna coding agents implemented changes. These audits do not replace educator review or learner studies.
- Questions and reference answers were authored separately from generated activities. Prepared corpus counts do not mean every case was generated or accepted.
- The algebra, geometry, and calculus activities are saved model-generated pages. Their archived HTML and mathematical state logic are unchanged in this v3 feature tour. The calculus graph is reduced in a separate filming stylesheet for legibility.

## Sharing activity provenance

The sharing activity is a derived local refinement of a saved AI-generated page. The original model output and assessment rules remain unchanged in the archive. The original page failed production validation because page-authored messages overwrote the host's assessment status and its recovery and invalidation traces restarted actions that should have continued from the current state. The derived copy redirects game messages to a separate accessible live region and uses continuation traces that recover both assessment steps and invalidate confirmations through a watched value. It passed the production checker and an independent 16-state browser audit. This is a locally refined artifact, not an unmodified model response.

The four model requests authorized for the earlier sharing demonstration were all used: two plan requests were rejected by provider schema handling, the third generated a plan, and the fourth generated the page. The v2 recording reused the third-call plan. The v3 feature tour reuses the saved pages and derived sharing copy, with no new model API requests.

## Media and data

The v3 feature tour uses saved model-generated activities. It opens on calculus, shows a sample derivative problem being typed into the composer without submitting it, and then explores the saved calculus, geometry, algebra, and sharing examples. No new model request is made for this video revision.

The narrated audio uses the installed macOS Samantha synthetic voice. FFmpeg assembles the video using a local imageio-ffmpeg distribution. No background music or stock footage is included. No private student records, real grades, or identifiable learner data are used. No learner-outcome study is claimed.
