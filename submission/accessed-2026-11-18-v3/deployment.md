# Deployment and delivery

This package prepares an English feature-tour video, screenshots, and project documents. The complete live-generation service has not been publicly deployed; a local address is not a public judge link.

To let judges submit new problems, deploy the Node.js and Chromium backend behind HTTPS and retain persistent usage limits. Keep any model API key on the server. Static HTML alone cannot run the current generation and browser-validation flow.

The four model requests authorized for the earlier strawberry recording were all used. The v3 feature-tour edit reuses saved footage and activities and makes no new API calls. The earlier authorization does not cover ongoing public-service usage. Decide on hosting, credentials, and a separate operating budget before offering live generation publicly.

Check the current event rules before submission. After uploading the video, enter a judge-accessible hosted link in Devpost. See the [official event page](https://accessed-hacks.devpost.com/) for current requirements.
